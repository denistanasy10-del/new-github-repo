# Security policy

## Supported versions

The project is in early development and has no formal release support window. Security fixes are prioritized for the current default branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's report-a-vulnerability flow](https://github.com/denistanasy10-del/new-github-repo/security/advisories/new), rather than opening a public issue.

Include the affected version, a description of the impact, and safe reproduction steps. Do not attach private photo libraries, credentials, or personal metadata.
